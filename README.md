# AgencyFlow

A SaaS client and project management platform designed for small digital agencies.

## Overview

AgencyFlow helps agencies organize clients, manage projects, track tasks and collaborate with clients through a centralized workspace.

## Core Features

- Multi-tenant agency workspaces
- User authentication and role-based access
- Client management
- Project management
- Task assignment and tracking
- Client-facing project portal
- Approval and feedback workflows
- Project reporting

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Node.js
- PostgreSQL
- Supabase
